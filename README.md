# Phonebook Management System

A Phonebook Management System developed as a Programming and Problem Solving Lab project.

## Features

- Add contacts
- View contacts
- Search contacts
- Update contacts
- Delete contacts
- Store contact information
- Web-based user interface

## Technologies

- C++
- HTML
- CSS
- JavaScript
- File Handling
- Socket Programming

## Project Structure

```text
Phonebook/

├── web/
│   ├── index.html
│   ├── script.js
│   └── style.css
├── README.md
└── .gitignore
```

## How to Run

### 1. Compile

On Windows, open a terminal in the project folder and run:

```bash
g++ server.cpp -std=c++17 -lws2_32 -o phonebook.exe
```

### 2. Run

```bash
phonebook.exe
```

### 3. Open in Browser

After starting the server, open:

```text
http://localhost:8081
```

## Project Purpose

This project demonstrates:

- User input
- Data processing
- File handling
- Searching
- Sorting
- User interaction
- Web-based interface

The project was developed to demonstrate programming concepts through a practical Phonebook Management System.

## Algorithm

The application processes and manages contact information and provides searching and sorting functionality.

Contacts can be organized by name to make searching more efficient.
