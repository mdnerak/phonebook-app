# Phonebook Management System

A console-based Phonebook Management System developed in C as a Programming and Problem Solving Lab project.

## Features

- Add contacts
- View contacts
- Search contacts
- Update contacts
- Delete contacts
- Save contacts to a file
- Load contacts from a file

## Technologies

- C Programming Language
- Structures
- Functions
- File Handling
- Modular Programming

## Project Structure

- `main.c` - Main program
- `contact.c` / `contact.h` - Contact management
- `phonebook.c` / `phonebook.h` - Phonebook operations
- `file.c` / `file.h` - File handling
- `ui.c` / `ui.h` - User interface

## How to Run

Compile the program using:

```bash
gcc main.c contact.c phonebook.c file.c ui.c -o phonebook
